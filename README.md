# [银河奶牛] Excel摸鱼模式

基于原作者的 Excel 换肤插件修改。一键将游戏界面切换为 Excel 表格风格，支持多种配色、图标显隐、物品中文名称和表格聊天，以熟悉的办公界面淡化游戏特征，方便低调摸鱼。

这是基于 Greasy Fork 脚本 573318（版本 1.0.5）的本地 fork 基线。

## 来源

- 原脚本：https://greasyfork.org/scripts/573318
- 原始源码：https://update.greasyfork.org/scripts/573318/MilkyWayIdle%20-%20Excel%E6%8D%A2%E8%82%A4.user.js

## 开始修改

脚本文件为 `milkywayidle-excel.user.js`。修改后请递增 `@version`，并在发布前将 `@downloadURL` / `@updateURL` 改为你自己仓库的地址或删除。

当前源码保留原作者的元数据和许可证声明。重新发布时请保留版权及 MIT 许可证，并明确列出你的修改。

## 本地修改

- 1.0.5.14：选择性合并修复版中的类名前缀兼容、聊天面板样式恢复、Excel 退出清理、根节点位置恢复、导航内容恢复、文本节点提及高亮和图片加载失败回退；删除未使用的依赖及上传代码，保留本仓库自动更新地址。
- 将延迟进入 Excel 的任务纳入退出清理，避免退出后被尚未执行的计时器重新打开。
- 保留原聊天去重与文字可见性处理，未合并修复版的节点数量阈值去重、游戏内联样式快照恢复和未经充分验证的 HTML 净化器。
- 验证：Node.js 语法检查、Git 空白检查和 jsdom 回归检查通过；覆盖面板样式往返恢复、提及高亮不改写链接属性、图片失败回退及计时器取消。尚未进行登录游戏后的浏览器实测。
- 修复开启“隐藏库存图标”后，从其他页面切换到“装备”页面时物品名称没有重新注入的问题。现在会在游戏根节点发生 React 页面更新时重新扫描并注入装备名称。
